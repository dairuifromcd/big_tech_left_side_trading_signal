# 停止与清理计划（待批准）

当前无远程资源、无部署、无 Secret、无 Alarm，需要清理的云端资源为 0。本地测试在项目 ignored 目录内；未自动删除用户文件。

候选 Gate B 默认选择 **停止、撤销凭据、保留隔离资源**，方便用户审阅证据：

1. stop 只作用获批固定实例，持久化 STOPPED，取消该实例 Alarm。
2. 只读确认 counters、Receipt、runs、Alarm=null，读取报告，保存脱敏审计和指标。
3. 删除初始化 Secret、停用 init flag；结束后删除控制/报告 Secret。必须明确批准这些远程写入及可能的活动版本更新。
4. 保留专用 Worker/namespace/SQLite 合成状态，记录准确资源及当前存储；入口无有效凭据，不能继续 start，窗口到期不能初始化或采集。保留存储继续占账户额度，不能称为“资源已删除”。

若用户要求删除：应在账户核实后补充并单独批准精确 namespace/class/Worker 删除流程，先导出必要证据；仅删除 Worker 不等于已删除 DO 存储。当前没有公开 deleteAll 或 SQL 清理 RPC，不为清理擅自加入后门。不得删除 namespace 中身份不明的对象，不可迁移或影响其他项目。

失败恢复：不确定初始化只读核验，未知状态不重试初始化；运行失败 stop+取消 Alarm+撤销本实验凭据，不 reset 数据或覆盖 checkpoint。若配额令 DO stop 写失败，使用事先批准的专用 Worker 停用/凭据撤销；具体 API/版本语义未获核验前不得执行。Gate B 授权不包括账户设置、付费、全局认证、其他项目资源。

本计划的可逆恢复方式是禁用执行入口并保留证据，恢复执行必须另行批准；不会把回滚旧版本当作清除持久化 STOPPED 或延长窗口的手段。
